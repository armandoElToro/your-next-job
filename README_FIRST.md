# Read Me First — Your Next Job

## Why this exists

Most job searches lose ground in two places: time spent chasing opportunities
that were never a real fit, and resumes that never survive the automated
screening most employers run before a person ever opens the file. This
plugin fixes both, in order — screen the opportunity first, then build a
resume and cover letter designed to be read by the screening system and the
person after it — and keeps a running record so nothing has to be
remembered or re-explained from one conversation to the next.

The goal is specific: get invited to a first interview, not just get an
application submitted.

## What to read, in order

1. **This file** — a two-minute orientation. You've already done this one.
2. **`docs/Your_Next_Job_Overview.docx`** — the full picture: why this
   approach works, the background you need to understand it, a glossary of
   terms, the five-stage process life cycle, and step-by-step instructions
   for getting started. Read this before your first real request if you
   want the full context.
3. **`docs/Your_Next_Job_Cheat_Sheet.docx`** — optional. A quick-reference
   table of every question the setup interview will ask, in case you'd
   rather think through your answers on paper first, or want to check or
   hand-edit a saved answer later.
4. **`README.md`** — the technical readme (what's in the plugin, how the
   setup and configuration mechanics work). Read this only if you want the
   under-the-hood details; it isn't required to use the plugin.

## Fastest way to get started

You don't need to read anything else to begin. Install the plugin, then
just talk to Claude naturally — for example, paste a job posting and ask
"should I apply to this?" The first real request automatically triggers a
short setup interview (your target titles, locations, pay floor, and so
on), and every stage of the workflow runs from your saved answers after
that. You can also say "set up my job search toolkit" any time to trigger
that interview on your own.
