# Job Search Configuration — TEMPLATE

status: template-not-yet-configured

This file is the example/fallback configuration shipped with the plugin
(one person's real search criteria, used to prove the workflow runs
end-to-end). **Do not run the workflow against these values for a new
user** — run the Setup Interview first (see
`references/setup-interview.md`) and write that user's real answers into a
project-level `job-search-config.md` file instead. The workflow always
prefers a project-level `job-search-config.md` over this template.

| Variable | Example value |
|---|---|
| Target titles | Release Train Engineer (RTE), Scrum Master, and direct synonyms: Chief Scrum Master, Senior/Technical/Lead Scrum Master, an explicit either/or title such as "Scrum Master / Agile Program Manager" |
| Titles that are automatically a no | Agile Coach, Agile Delivery Lead, Product Owner, Product Manager, Project Manager, Trainer, or any "transformation leader" title |
| Onsite/hybrid locations accepted | San Antonio, TX; Austin, TX; Dallas-Fort Worth (DFW), TX |
| Remote accepted? | Yes — fully remote anywhere in the U.S. |
| Pay floor — W2 or C2C contract | $60/hour all-in |
| Pay floor — FTE | ~$125,000/year base |
| Pay floor — premium onsite market (optional) | $70/hour, or ~$146,000/year FTE, for 100% onsite in Austin or DFW specifically |
| Minimum contract length | 6 months, with a stated extension or conversion path (does not apply to FTE or open-ended consulting) |
| Industries preferred | Regulated / compliance-heavy: banking, insurance, federal/government, healthcare |
| Clearance/authorization notes | Previously held an active federal Public Trust and Secret clearance; lapsed after sponsorship ended, not due to any disqualifying finding |
| Baseline resume data source | A single, current document holding real, complete career history |
| Resume document format | 11pt, standard margins |
| Other document format (cover letters, prep packets) | MS Word (.docx), minimum 14pt font, 2-inch top margin, navy/gray palette |
| Standing resume/cover-letter corrections | Certification names must match the actual certificate exactly; say "coached" not "led" when the person coached rather than personally led an initiative; always include a LinkedIn URL in the contact line |
| Age-related bias coaching (optional) | Reframe long experience as pattern recognition, not tenure; lead every interview answer with a recent example; use future-tense language; avoid referencing technology or methods older than ~10 years |
| Prompt-discipline threshold (optional) | Score any prompt longer than 150 characters against a 4-part rubric (Clarity, Scope, Context, Format); log every scored prompt to a single master prompt log |
